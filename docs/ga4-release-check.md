## 本轮已保存的配置修正

在 管理 → 数据流 → TopPerfume Website → 增强型衡量设置：

1. 关闭“出站点击事件”：现有自定义 WhatsApp 事件继续保留；自动出站事件会采集 link_url，而后续 WhatsApp 草稿 URL 可含客户输入，故避免自动采集整条草稿链接。

上述参数含义依据 [Google 增强型衡量说明](https://support.google.com/analytics/answer/9216061?hl=en)。恢复方案为在同一面板恢复这两项原开关（都为开启）；不建议在未经处理的询盘草稿 URL 上恢复自动出站采集。
