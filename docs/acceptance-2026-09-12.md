# TopPerfume 本轮统一验收结果

验收日期：2026-09-12。范围仅为询盘表单修复、发布资料与 Preview 交付。未调整产品价格、容量、MOQ、图片或页面设计，未合并 main，未发布 Production。

## 表单验收：通过（模拟邮件接收端）

使用实际网页、Express/tRPC 路由、服务器校验、产品解析和邮件正文生成，仅将最后的邮件传输替换为本地内存接收端。接收端使用 `.invalid` 测试地址和假密钥，禁止外部 fetch；没有发送真实邮件。

| 场景 | 实际结果 |
|---|---|
| 必填项为空、邮箱格式错误 | 浏览器阻止提交，模拟接收端调用数为 0 |
| 502 mL 产品数量为 1（低于 MOQ 2）、2.5（非整数） | 阻止提交，模拟接收端调用数为 0 |
| 桌面产品表单填写并提交 | 成功反馈和询盘编号显示；表单隐藏 |
| 连续双击、请求等待期间按 Enter、尝试关闭表单 | 请求只到达模拟接收端一次；按钮禁用，活动表单保留 |
| 模拟邮件服务返回 503 | 显示失败提示，保留表单，可由用户主动重试；没有自动重发 |
| 失败后关闭并重新打开 | 已修复旧错误残留，重新打开时没有旧错误 |
| 成功后选择再次询盘 | 恢复可填写状态，不自动发送 |
| 375 × 812 手机联系页填写并提交 | 成功，编号 TP-706D5B3B；弹层及页面宽度均为 375 px，无横向溢出 |
| 产品正文及 WhatsApp 后续草稿 | 502 mL、MOQ 2 瓶、US$2.99/瓶、数量 2、小计 US$5.98 一致；小计不含运费税费，最终条件逐单书面确认 |

已修复三个问题：新表单残留上次失败提示；快速操作的同步防重复保护不足；成功后 WhatsApp 草稿使用相对产品网址。现已输出完整产品网址。未点击发送 WhatsApp。

防重复验证范围为同一打开表单的一次请求及其成功状态，不声称跨浏览器、刷新页面或网络响应丢失时具有持久化幂等保证。用户主动选择再次询盘属于新请求。

类型检查通过；`server/whatsappCta.test.ts`、`server/finalization.test.ts` 共 13 项测试通过；生产模式构建通过（保留既有分包大小提示）。没有重复全站扫描或已通过的产品/响应式检查。

此前唯一真实 TEST 邮件的 Resend Delivered 及用户实际收件验证继续为通过，不再发送。本轮关闭的是“网页完整流程模拟验收”缺项；实际邮箱回复操作、真实 GA4 事件验收仍未测试。没有把模拟结果说成新一轮真实邮件送达。
